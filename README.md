# Argent media

Images for Argent's Modrinth page. The mod's code is on the `main` branch.

Files here are linked as:

```
https://raw.githubusercontent.com/Khrux/argent/media/<folder>/<file>
```

Replacing a file under the same name updates the page within about five minutes.

## Banners

Full-width headings. The description column is about 900 px wide on a computer, so banners are exported at double that to stay sharp on high-resolution screens.

- `argent.png`, the title: 1800 x 450, one and a half times a section banner
- Every section banner: exactly 1800 x 300 (6:1), so the headings line up the whole way down
- Keep the important part and any text inside the middle 1500 px or so; on phones banners shrink to about 360 px wide
- Animated banners: GIF at 900 x 150 (900 x 225 for the title), under about 5 MB each, and change `.png` to `.gif` in that banner's line of the description

## Stickers

Not in use yet. Cut-outs that sit to the right of the text. Transparent background, with rotation and outline already applied. They're shown 220 px wide, so export them 440 px wide, measured after rotating and outlining.

- Square: 440 x 440
- Up to 440 x 660 (2:3) for tall ones
- Landscape ones (up to 640 x 440) need `width="320"` in their line of the description
