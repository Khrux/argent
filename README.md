# Argent media

Images for Argent's Modrinth page. The mod's code is on the `main` branch.

Files here are linked as:

```
https://raw.githubusercontent.com/Khrux/argent/media/<folder>/<file>
```

Replacing a file under the same name updates the page within about five minutes.

## Banners

Full-width section headings. About 1800 px wide, so they stay sharp on high-resolution screens. Keep every banner the same height so the page has a steady rhythm. PNG, or GIF for an animated one (then change `.png` to `.gif` in that banner's line of the description).
